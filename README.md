# AI営業受注型 Web制作システム - Phase 1 MVP（v3.0 営業特化版）

## プロジェクト概要

最小入力フォーム（**7項目**）から高品質な営業用ホームページを半自動生成するシステム。
v3.0では**情報商材系LPの「売れる構成」**を徹底的に取り入れ、コンバージョン最大化を実現。

**コンセプト**: Zero-Friction Intake & AI Harness × 営業力最強LP

### apply.html のコンバージョン最適化

- **緊急性バー**: 「残りX枠」表示

- **信頼バッジ**: SSL暗号化・クレカ不要・営業電話なし
- **CTA**: グラデーション+パルスアニメーション

## 実装済み機能 ✅

### 1. 営業特化LP（index.html）
- 緊急性トップバー（月名・残り枠数を自動算出）
- ファーストビュー（痛み→希望→信頼数字→メインCTA）

- お悩み共感セクション（4つのペインポイント）
- 3ステップソリューション
- Before/After比較表
- 驚異の実績（4つの数字カード + メディアロゴ）
- お客様の声（3名 + 具体的成果数値 + 星評価）
- 中間CTA
- 選ばれる6つの理由
- 使い方ガイド（3ステップ詳細 + 所要時間表示）
- 料金プラン（3段階 + 値引き演出）
- 3つの安心保証
- FAQ（6項目）
- ファイナルCTA（緊急性 + 3つの安心ポイント）
- モバイル固定CTA（スクロールで表示）
- IntersectionObserver によるスクロールアニメーション
- カウントアップアニメーション

### 2. コンバージョン最適化フォーム（apply.html）
- 7項目入力（セクションA: 基本4項目 + セクションB: AI精度UP 3項目）
- 業種選択→プレースホルダー自動変更 + ヒント表示
- リアルタイム進捗バー + AI精度予測インジケーター
- サイドバー（緊急性オファー・ソーシャルプルーフ・安心保証）
- AI分析シミュレーション（送信後の処理アニメーション）
- 業種確定による高精度モード（信頼度100%）

### 3. 管理画面（admin.html）
- ダッシュボード（統計カード + Chart.jsグラフ）
- 案件一覧（検索・フィルタ・業種バッジ）
- 案件詳細（5タブ: 概要/プロファイル/分析/評価/ログ）
- 承認/差戻し/再実行ワークフロー

### 4. 共通ユーティリティ（js/api.js）
- RESTful Table API通信
- 業種/目的/ステータスのマスターデータ
- バッジ生成関数
- トースト通知
