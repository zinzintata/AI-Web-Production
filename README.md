# AI営業受注型 Web制作システム - Phase 1 MVP（v2.0 統合改善版）

## プロジェクト概要

最小入力フォーム（**7項目**: 会社名・住所・メール・参考URL + **業種・主力サービス・サイト目的**）から高品質な営業用ホームページを半自動生成するシステムのPhase 1 MVPです。

**コンセプト**: Zero-Friction Intake & AI Harness
- 顧客入力は最適化された7項目（入力時間3〜5分、離脱率目標≤30%）
- AI側で最大補完（公開情報探索、参考サイト構造解析、事業意図推定）
- 著作権クリーンな模倣（構造・UI文法のみ抽出、コンテンツは完全差し替え）
- 品質保証ループ（評価エージェントによる自動採点 + 改善エージェントによる局所修正）

## v2.0 更新内容（フォーム最適化）

### 追加された3項目

| # | 項目名 | フィールドID | 入力形式 | バリデーション | AI生成への影響度 |

| 5 | 業種 | `industry` | プルダウン選択（15選択肢、絵文字付き） | 必須、15選択肢 | **高**（+36%精度） |

### 設計原則
- **心理的ハードル最小化**: 専門用語回避、即答可能な質問のみ
- **入力支援の充実**: 業種選択→プレースホルダー自動変更、AI生成精度予測バー
- **エラー防止**: リアルタイムバリデーション、進捗表示（0/7 → 7/7）
- **モバイル最適化**: スマートフォンでの入力しやすさ

### 1. 営業用トップページ（LP）
- **ファイル**: `index.html`
- Hero セクション（7項目→約3〜5分入力の訴求）
- How It Works（4ステップ解説、7項目入力フロー）
- 特長セクション（6つの特長カード）

- Final CTA、レスポンシブ対応
- ナビゲーションスクロール効果、パーティクルアニメーション、カウントアップ

### 2. 最小入力申込フォーム（v2.0: 7項目）
- **ファイル**: `apply.html`
- **セクションA（基本情報4項目）**: 会社名（100文字）、住所（200文字）、メール（RFC準拠）、参考URL（http/https）
- **セクションB（AI精度向上3項目）**:
  - 業種プルダウン（15選択肢、絵文字付き）
  - 主力サービス（業種選択で動的プレースホルダー変更、150文字以内）
  - サイト目的チェックボックス（6選択肢、複数選択可）
- リアルタイム入力進捗バー（0/7 → 7/7）
- **AI生成精度予測バー**（項目入力に応じてリアルタイム更新: 基本精度 → 85点〜）
- 業種選択時のヒント表示（業種別のAI生成内容プレビュー）
- 各新項目に「精度+XX%」バッジ表示
- サイドバーに7項目入力の効果数値を表示
- 補足情報アコーディオン（任意、500文字以内）

### 3. AI分析シミュレーション（v2.0: 高精度モード）
- 業種をConfirmed情報として使用（推定不要 → 信頼度100%）
- 業種×サイト目的に基づくビジネスタイプ推定（BtoB/BtoC/店舗型）
- サイト目的に基づくセクション構造自動生成（hero → services → about → CTA → contact → footer）
- 業種別ブランドトーン自動設定（professional/friendly/casual/premium）
- 業種別ペインポイント自動生成
- 7項目入力による品質スコア向上（平均93点）

### 4. 管理画面（v2.0: 新フィールド対応）
- **ファイル**: `admin.html`
- **ダッシュボード**: 統計カード4枚（総案件数、処理中、レビュー待ち、平均スコア）
- **Chart.jsグラフ**: ステータス分布（ドーナツ）、品質スコア推移（バー）
- **案件一覧**: 検索・ステータスフィルタ、業種バッジ表示
- **案件詳細** (5タブ):
  - 概要: Confirmed Data（7項目表示）、パイプライン進捗
  - 事業プロファイル: Inferred/Assumed データ分類表示
  - 参考サイト分析: ページ構造、配色パレット、UIパターン
  - 品質評価: 7軸スコアバー、総合スコアリング、合否判定、フィードバック
  - 処理ログ: エージェント別ログタイムライン
- **承認/差戻し/再実行ワークフロー**
- レスポンシブサイドバー（モバイル対応）

### 5. 共通ユーティリティ（v2.0拡張）
- **ファイル**: `js/api.js`
- `API` オブジェクト: RESTful Table APIとの通信（CRUD + ページネーション + 検索）
- `INDUSTRY_MAP`: 15業種のアイコン・カラー・プレースホルダー定義
- `SITE_GOALS_MAP`: 6目的のアイコン・カラー・説明定義
- `STATUS_MAP`: 8ステータスのラベル・カラー・アイコン定義
- `getIndustryBadge()`, `getSiteGoalBadges()`, `getStatusBadge()`: バッジHTML生成
- `generateUUID()`, `formatDate()`, `showToast()`: 共通ユーティリティ

### TypeScript型定義

```typescript
interface ApplicationFormData {
  // 基本情報（セクションA）
  companyName: string;       // 会社名/屋号（必須、100文字以内）
  address: string;           // 住所（必須、200文字以内）
  email: string;             // メールアドレス（必須、RFC準拠）
  referenceUrl: string;      // 参考サイトURL（必須、http/https形式）
  
  // AI精度向上情報（セクションB）
  industry: IndustryType;    // 業種（必須、15選択肢から選択）
  mainServices: string;      // 主力サービス・商品（必須、150文字以内）
  siteGoals: SiteGoalType[]; // サイトの主な目的（必須、1つ以上選択）
  
  // 補足（任意）
  additionalNotes?: string;  // 補足情報（任意、500文字以内）
}

type IndustryType = 
  | 'IT・Web' | '飲食店' | '小売・小売業' 
  | '士業（法律・税理・行政書士等）' | '医療・クリニック'
  | '建設・工務店' | '製造業' | '教育・スクール' 
  | '不動産' | '美容・サロン' | 'コンサルティング'
  | '整体・治療院' | '運送・物流' | '介護・福祉' | 'その他';

type SiteGoalType = 
  | '問い合わせ獲得' | '来店予約' | '資料請求' 
  | '採用応募' | '商品販売' | 'ブランド認知';
```

### 3層データ信頼度（v2.0改善）

| レベル | v1.0 | v2.0 | 変化 |
|--------|------|------|------|
| **Confirmed** | 4項目 | **7項目** | 業種・サービス・目的が確定情報に昇格 |
| **Inferred** | 業種・サービスエリア等 | サービスエリア等（少量） | 大幅削減 |
| **Assumed** | ターゲット・課題・価値等 | ターゲット・課題（少量） | 大幅削減 |
